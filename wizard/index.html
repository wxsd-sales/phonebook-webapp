Host it on your own web server

  1. Unzip the download. It contains a single phonebook-webapp/ folder with index.html at its top level.
  2. Copy the folder to your internal web server, for example into the document root so it is served from https://phonebook.example.com/phonebook/. Any static web server works (nginx, Apache, IIS, ...); no server-side code is needed. Serve it over HTTPS and make sure your devices can reach that FQDN. No certificate, or only an IP address? See the note on insecure HTTPS in the next step.
  3. Point the macro at it. On the tab, set Web app URL to the full FQDN and path of your copy, e.g. https://phonebook.example.com/phonebook/. If the server uses a self-signed certificate or is addressed by IP (e.g. https://10.0.0.5/phonebook/), also turn on Allow insecure HTTPS; the macro then adds that host to the device's WebEngine allow list.
  4. Choose the directory. With the example directory included, leave Phonebook root URL blank. Otherwise put your own CiscoIPPhoneDirectory XML on your server and set Phonebook root URL to it (a path relative to the web app, or a full URL; a different host must allow cross-origin requests).
  5. Export the macro from the tab and deploy it to your device.
